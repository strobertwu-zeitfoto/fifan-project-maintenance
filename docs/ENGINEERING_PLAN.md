# Fifan Project Maintenance — Engineering Plan

## 当前目标与授权

目标版本 **1.5.0**，开发基线 fa70b7c7e367265bcd14a1e1bc39ad8639e7436a。2026-11-14 用户批准从三个治理案例总结工具改进，分阶段实施，以临时样例测试和独立复核后更新本机；随后明确授权提交、推送 GitHub，并补齐下载入口。本次使用 v1.5.0 GitHub Release、版本标签、源码/Skill/wheel 和校验文件完成下载交付，不发布到包索引。

本文件为唯一工程计划，由主 Agent 维护。三个真实业务项目不在实施或测试范围。Python >=3.9 兼容声明及固定运行依赖保留；平台实测范围单独记录。原完整本机过程记录和恢复材料保留在本地，公开版仅收录可移植的目标、决定、验收结果和边界。

- 维护功能完整回归 **1104 passed / 105.62s**：Apple Silicon macOS、Python 3.12.16，固定依赖，全部为临时合成工程。

- 1.5新增路径分组独立静态复核最终均为限定 **NoMustfix**；没有把静态复核当运行测试或全项目深审。
- 本机部署驱动另完成17个临时场景，涵盖目录/链接漂移、后改保护、回退及同版本旧包拒绝；驱动和本机记录不随公开源码发布。

## 保留的边界

- 分批为显式 opt-in；累计 bytes/files 约束每次完整声明集合，续办重验 IO 单独计量，累计时间沿检查点保留。检查点仅用于检查，不能直接授权写操作。
- 复核包不自动证明没有动态依赖；联合预演的新增引用文件仍 Unknown，也不是原生归档计划。
- 字面保留不等于语义等价，绑定影响不生成加载凭证；声明的搜索集合不冒充实际编辑器结果。
- 内容备份、回退资格、永久 purge 和物理空间释放分开。旧editable安装回退时须同时恢复源文件与环境。
- 1.5.0 未在三个真实业务项目、Windows、Linux、自由线程 Python 或其他未列平台验收。既有 Intel 历史结果不扩充为本版本实测。
