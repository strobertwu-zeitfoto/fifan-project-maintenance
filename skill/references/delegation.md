# 可选维护者工作流

下列角色是既有Fifan/Codex配置，CLI不依赖它们。未安装时由主Agent处理必要判断；需要独立只读角色却缺隔离入口时保留Blocked，不用宽权限角色冒充。不要据此宣称其他Agent软件已适配。

# 按需分派语义工作

仅在复杂跨合同、较大批量正文瘦身或低耦合附件确有独立收益时读取。常规三份 MD 由 Root 与 CLI 完成，不为每份文件创建 Agent。

- 机械统计、哈希、引用、逐字归档覆盖、日志验证均由 CLI 完成，CLI 不调用模型或自动启动 Agent。
- Root 使用 gpt-6.1-sol/medium，负责目标、唯一计划、核心决定、工程接受与整合；使用期大批默认同时最多两个子任务，不设固定协调者或 PM 层。
- `fifan_explorer` 使用 gpt-6-luna/medium，对明确限定原件筛选语义疑点；实质冲突交 `fifan_complex_investigator`，重要要求是否遗漏的独立核对交 `fifan_reviewer`，两者使用 gpt-6.1-sol/high。这些只读角色只经既有固定受限 CLI；调用前读 `<CODEX_HOME>/fifan-readonly/calling.md`，材料逐项限域，不用同名原生/default 或宽权限会话替代。缺入口保留原错误，仅暂停依赖部分。
- 低耦合附件可交 `fifan_implementer`（gpt-6.1-sol/medium），写范围明确且不重叠；不交出唯一计划和核心决定。没有独立收益时不派协调者、PM 或 Tester 重复机械回执。
- 短任务包写明目标、准确材料、写范围、真实入口、有效证据、缺口和停止条件；新任务默认 fork_turns=none。返回问题、位置、依据与 Unknown，先为 reported；Root 按风险补读关键原件后接受，不重新通读全部材料。

复用原 Agent 和有效证据，固定角色不在运行中换模型；模型或隔离能力不可用如实报告，不替换、购买或更改全局默认。低价模型不等于整次额度更省，模型实际用量拿不到仍 Unknown。这里的最多两子任务是工具使用期默认，不改本工具开发时明确批准的实施/测试派工合同。
